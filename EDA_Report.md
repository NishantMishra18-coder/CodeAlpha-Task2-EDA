
# Exploratory Data Analysis (EDA) Report

## 1. Project Overview
This project explores a retail sales dataset to identify
patterns in sales, profit, product categories and regions.

## 2. Dataset Overview
- Total records: 9994
- Total columns: 21
- Duplicate rows: 0
- Missing values: 5952

## 3. Key Metrics
- Total Sales: 2,297,200.86
- Total Profit: 286,397.02

## 4. Category Analysis
- Highest sales category: Technology
- Lowest sales category: Office Supplies

## 5. Regional Analysis
- Highest total profit region: West
- Lowest total profit region: Central

## 6. Analysis Performed
- Dataset structure and data types
- Missing values and duplicate checks
- Category and regional analysis
- Monthly sales trends (where date data is available)
- Correlation and outlier analysis

## 7. Conclusion
The analysis helps identify sales patterns and areas
for further business investigation. Recommendations
should be based on the observed results.
